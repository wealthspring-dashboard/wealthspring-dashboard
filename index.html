Need Help?

Integration guides below. Contact us for support.

QuickBooks Online

Sync P&L, Balance Sheet, and customer revenue data in real-time.

1. Go to developer.intuit.com and create a new app
2. Copy your Client ID and Client Secret
3. Set redirect URI: https://wealthspring-dashboard.vercel.app/auth/callback
4. Paste credentials in Integrations section above
FinancialCents

Sync project data and billable hours for profitability analysis.

1. Log into FinancialCents → Settings → API Keys
2. Copy your API key
3. Enable sync in Integrations section above
Liscio CRM

Sync client communications and opportunity tracking.

1. Log into Liscio → Settings → API Keys
2. Copy your API key
3. Enable sync in Integrations section above
